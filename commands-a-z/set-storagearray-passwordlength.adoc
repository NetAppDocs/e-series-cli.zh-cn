= 设置存储阵列密码长度 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
使用`set storageArray passwordlength`命令、管理员用户可以为存储阵列上的所有新密码或更新后的密码设置最小长度。



[[supported-arrays]]
== 支持的阵列

此命令适用于单个 E4000、E2800、E5700、EF600、EF300、EF50 和 EF80 存储阵列。不适用于 E2700 或 E5600 存储阵列。



[[roles]]
== 角色

要在 E4000、E2800、E5700、EF600、EF300、EF50 或 EF80 存储阵列上执行此命令，必须具有 Security Admin 角色。



[[syntax]]
== 语法

[source, cli]
----
set storageArray passwordLength=<INTEGER>
----


[[parameters]]
== Parameters

[cols="2*"]
|===
| 参数 | Description 


 a| 
`密码长度`
 a| 
用于设置所有新密码或已更新密码所需的最小长度。



 a| 
`整型`
 a| 
用于为所有新密码或更新的密码设置所需的最小长度、介于0到30之间。

|===


[[examples]]
== 示例

[listing]
----

SMcli <array_ip> -u <username> -p <password> -c "set storageArray passwordLength=0;"

SMcli completed successfully.
----
