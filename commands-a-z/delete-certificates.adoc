= 删除证书 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
使用`Delete certificates`命令可以从命令行界面软件包信任存储中删除证书。



[[supported-arrays]]
== 支持的阵列

此命令适用于 EF600、EF300、EF50 和 EF80 存储阵列。



[[syntax]]
== 语法

[source, cli, subs="+macros"]
----
delete localCertificate all | alias pass:quotes[_alias_]
----


[[parameters]]
== Parameters

|===
| 参数 | Description 


 a| 
`别名`
 a| 
用于通过用户定义的别名指定证书。

|===


[[minimum-firmware-level]]
== 最低固件级别

8.60
