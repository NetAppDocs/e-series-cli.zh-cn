= 显示存储阵列控制器运行状况图像 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
`sstorageArray controllerHealthImage`命令可在支持控制器运行状况映像的存储阵列上显示控制器缓存上的控制器运行状况映像的详细信息(如果有控制器运行状况映像)。



[[supported-arrays]]
== 支持的阵列

此命令适用于任何单个存储阵列，包括 E4000、E2700、E5600、E2800、E5700、EF600、EF300、EF50 和 EF80 阵列，前提是所有 SMcli 包均已安装。



[[roles]]
== 角色

要在 E4000、E2800、E5700、EF600、EF300、EF50 或 EF80 存储阵列上执行此命令，必须具有 Storage Admin 或 Storage Monitor 角色。



[[context]]
== 环境

[NOTE]
====
对于固件版本8.20、`coredump`参数将替换为`controllerHealthImage`参数。

====
如果存储阵列不支持控制器运行状况映像功能、则此命令将返回错误。



[[syntax]]
== 语法

[source, cli]
----
show storageArray controllerHealthImage
----


[[parameters]]
== Parameters

无



[[minimum-firmware-level]]
== 最低固件级别

7.83.

8.20将`coredump`参数替换为`controllerHealthImage`参数。
