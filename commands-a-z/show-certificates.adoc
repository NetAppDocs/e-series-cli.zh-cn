= 显示证书 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
使用`Show certificates`命令可以查看CLI软件包信任存储上安装的证书。



[[supported-arrays]]
== 支持的阵列

此命令适用于 EF600、EF300、EF50 和 EF80 存储阵列。



[[syntax]]
== 语法

[source, cli]
----
show localCertificate all | alias alias
----


[[parameters]]
== Parameters

[cols="2*"]
|===
| 参数 | Description 


 a| 
`别名`
 a| 
用于通过用户定义的别名指定证书。

|===


[[minimum-firmware-level]]
== 最低固件级别

8.60
