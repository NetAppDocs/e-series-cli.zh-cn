= 显示存储阵列主机 I/O 协议信息 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
该  `show storageArray hostIoProtocolInformation` 命令显示有关特定存储阵列的 I/O 协议设置的信息。



[[supported-arrays]]
== 支持的阵列

此命令适用于E4000、EF50或EF80存储阵列，前提是所有SMcli软件包均已安装。



[[roles]]
== 角色

要在 E4000、EF50 或 EF80 存储阵列上执行此命令，必须具有 Support Admin 角色。



[[syntax]]
== 语法

[source, cli, subs="+macros"]
----
show storageArray hostIoProtocolInfo;
----


[[parameter]]
== 参数

无



[[minimum-firmware-level]]
== 最低固件级别

12.00
