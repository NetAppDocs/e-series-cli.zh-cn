= 显示存储阵列用户会话 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
使用`sstorageArray userSession`命令可以查看System Manager的会话超时期限。



[[supported-arrays]]
== 支持的阵列

此命令适用于单个 E4000、E2800、E5700、EF600、EF300、EF50 和 EF80 存储阵列。不适用于 E2700 或 E5600 存储阵列。



[[roles]]
== 角色

要在 E4000、E2800、E5700、EF600、EF300、EF50 或 EF80 存储阵列上执行此命令，必须具有 Storage Admin 或 Support Admin 或 Storage Monitor 角色。



[[parameters]]
== Parameters

无



[[syntax]]
== 语法

[source, cli]
----
show storageArray userSession
----


[[minimum-firmware-level]]
== 最低固件级别

8.41
