= 恢复禁用的驱动器端口 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
`re封面已禁用驱动器端口`命令可恢复已禁用的驱动器端口。



[[supported-arrays]]
== 支持的阵列

此命令适用于任何单个存储阵列，包括 E4000、E2700、E5600、E2800、E5700、EF600、EF300、EF50 和 EF80 阵列，前提是所有 SMcli 包均已安装。



[[roles]]
== 角色

要在 E2800、E5700、EF600、EF300、EF50 或 EF80 存储阵列上执行此命令，必须具有 Storage Admin 角色。



[[syntax]]
== 语法

[source, cli]
----
recover disabled drivePorts;
----


[[examples]]
== 示例

[listing]
----
recover disabled drivePorts;
