= 停止检查卷奇偶校验作业 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
。 `stop check volume parity job` 命令用于停止正在进行的检查卷奇偶校验作业。



== 支持的阵列

此命令适用于任何单个存储阵列，包括 EF600、EF300、EF50 和 EF80 阵列；只要安装了所有 SMcli 包。



== 角色

要在 EF600、EF300、EF50 和 EF80 存储阵列上执行此命令，必须具有 Storage Admin 角色。



== 语法

[source, cli, subs="+macros"]
----
stop check volume parity job jobId=<job_id>;
----


== Parameters

|===
| 参数 | Description 


 a| 
`jobId`
 a| 
要停止的检查卷奇偶校验作业对应的作业ID。此值为必填项。

|===


== 最低固件级别

11.80
