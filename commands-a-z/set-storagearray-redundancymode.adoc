= 设置存储阵列冗余模式 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
`set storageArray redundancyMode`命令可将存储阵列的冗余模式设置为单工或双工。



[[supported-arrays]]
== 支持的阵列

此命令适用于任何单个存储阵列，包括 E4000、E2700、E5600、E2800、E5700、EF600、EF300、EF50 和 EF80 阵列，前提是所有 SMcli 包均已安装。



[[roles]]
== 角色

要在 E4000、E2800、E5700、EF600、EF300、EF50 或 EF80 存储阵列上执行此命令，必须具有 Storage Admin 角色。



[[syntax]]
== 语法

[source, cli]
----
set storageArray redundancyMode=(simplex | duplex)
----


[[parameter]]
== 参数

[cols="2*"]
|===
| 参数 | Description 


 a| 
`redundancyMode`
 a| 
如果只有一个控制器、请使用`simplicx`模式。如果有两个控制器、请使用`duplex`模式。

|===


[[minimum-firmware-level]]
== 最低固件级别

6.10
