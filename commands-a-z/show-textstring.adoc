= 显示字符串 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
`show textstring`命令显示脚本文件中的文本字符串。此命令类似于MS-DOS和UNIX中的`echo`命令。



[[supported-arrays]]
== 支持的阵列

此命令适用于任何单个存储阵列，包括 E4000、E2700、E5600、E2800、E5700、EF600、EF300、EF50 和 EF80 阵列，前提是所有 SMcli 包均已安装。



[[roles]]
== 角色

要在 E4000、E2800、E5700、EF600、EF300、EF50 或 EF80 存储阵列上执行此命令，必须具有 Storage Admin 或 Storage Monitor 角色。



[[syntax]]
== 语法

[source, cli, subs="+macros"]
----
pass:quotes[show "_textString_"]
----


[[parameters]]
== Parameters

无



[[notes]]
== 注释：

请将此字符串用双引号("")括起来。



[[minimum-firmware-level]]
== 最低固件级别

6.10
