= 重置存储阵列 RLS 基线 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
`reset storageArray RLSBASeline`命令可通过将所有RLS计数设置为0来重置所有设备的读取链路状态(RLS)基线。



== 支持的阵列

此命令适用于任何单个存储阵列，包括 E4000、E2700、E5600、E2800、E5700、EF600、EF300、EF50 和 EF80 阵列，前提是所有 SMcli 包均已安装。



== 角色

要在 E4000、E2800、E5700、EF600、EF300、EF50 或 EF80 存储阵列上执行此命令，必须具有 Storage Admin 角色。



== 语法

[source, cli]
----
reset storageArray RLSBaseline
----


== Parameters

无

5：00
