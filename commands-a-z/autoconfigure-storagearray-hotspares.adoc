= 自动配置存储阵列热备用 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
`autoConfigure storageArray hotspares`命令可自动定义和配置存储阵列中的热备用磁盘。您可以随时运行此命令。此命令可为存储阵列提供最佳热备用磁盘覆盖范围。



[[supported-arrays]]
== 支持的阵列

此命令适用于任何单个存储阵列，包括 E4000、E2700、E5600、E2800、E5700、EF600、EF300、EF50 和 EF80 阵列，前提是所有 SMcli 包均已安装。



[[roles]]
== 角色

要在 E4000、E2800、E5700、EF600、EF300、EF50 或 EF80 存储阵列上执行此命令，必须具有 Storage Admin 角色。



[[syntax]]
== 语法

[source, cli]
----
autoConfigure storageArray hotSpares
----


[[parameters]]
== Parameters

无



[[notes]]
== 注释：

运行`autosupport storageArray hotspares`命令时、控制器固件会根据存储阵列中的驱动器总数和类型确定要创建的热备用磁盘数。对于SAS驱动器、控制器固件会为存储阵列创建一个热备用磁盘、并为存储阵列中的每60个驱动器创建一个额外的热备用磁盘。



[[minimum-firmware-level]]
== 最低固件级别

6.10
