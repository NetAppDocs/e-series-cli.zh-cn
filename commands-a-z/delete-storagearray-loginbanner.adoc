= 删除存储阵列登录横幅 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
使用`delete storageArray loginbanner`命令可以删除先前上传并保存的登录横幅文本文件。



== 支持的阵列

此命令适用于单个 E4000、E2800、E5700、EF600、EF300、EF50 和 EF80 存储阵列。不适用于 E2700 或 E5600 存储阵列。



== 角色

要在 E4000、E2800、E5700、EF600、EF300、EF50 或 EF80 存储阵列上执行此命令，必须具有 Security Admin 角色。



== 语法

[source, cli]
----
delete storageArray loginBanner
----


== Parameters

无

8.41
