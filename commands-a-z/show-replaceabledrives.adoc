= 显示可更换驱动器 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
`show replaceableDrives`命令可显示存储阵列中的所有可更换驱动器。



[[supported-arrays]]
== 支持的阵列

此命令适用于任何单个存储阵列，包括 E4000、E2700、E5600、E2800、E5700、EF600、EF300、EF50 和 EF80 阵列，前提是所有 SMcli 包均已安装。



[[roles]]
== 角色

要在 E4000、E2800、E5700、EF600、EF300、EF50 或 EF80 存储阵列上执行此命令，必须具有 Storage Admin 角色。



[[context]]
== 环境

对于存储阵列中的每个可更换驱动器、此命令将返回以下信息：

* 托盘位置和插槽位置
* 驱动器所属的卷组名称
* 全球通用名称(WWN)
* 驱动器的状态




[[syntax]]
== 语法

[source, cli]
----
show replaceableDrives
----
