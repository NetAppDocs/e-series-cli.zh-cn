= 启动存储阵列系统日志测试 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
使用`sStart storageArray syslog test`命令可以测试存储阵列与系统日志服务器之间的通信。



[[supported-arrays]]
== 支持的阵列

此命令适用于单个 E4000、E2800、E5700、EF600、EF300、EF50 和 EF80 存储阵列。不适用于 E2700 或 E5600 存储阵列。



[[roles]]
== 角色

要在 E4000、E2800、E5700、EF600、EF300、EF50 或 EF80 存储阵列上执行此命令，必须具有 Security Admin 角色。



[[syntax]]
== 语法

[source, cli]
----
start storageArray syslog test id="<id>"
----


[[parameters]]
== Parameters

[cols="2*"]
|===
| 参数 | Description 


 a| 
id
 a| 
要测试的系统日志配置ID。可以使用`show storageArray syslog`命令获取此ID。

|===


[[example]]
=== 示例

[listing]
----
SMcli -n Array1 -c "start storageArray syslog test
id=\"331998fe-3154-4489-b773-b0bb60c6b48e\";"
SMcli completed successfully.
----
