= 恢复卷组 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
使用`revve VolumeGroup`命令可将指定卷组及其关联的故障驱动器强制设置为最佳状态。



[[supported-arrays]]
== 支持的阵列

此命令适用于任何单个存储阵列，包括 E4000、E2700、E5600、E2800、E5700、EF600、EF300、EF50 和 EF80 阵列，前提是所有 SMcli 包均已安装。



[[roles]]
== 角色

要在 E4000、E2800、E5700、EF600、EF300、EF50 或 EF80 存储阵列上执行此命令，必须具有 Storage Admin 或 Support Admin 角色。



[[context]]
== 环境

[NOTE]
====
*可能丢失数据访问*-正确使用此命令取决于卷组中所有驱动器上的数据配置。除非您受到技术支持的监督、否则请勿尝试恢复驱动器。

====


[[syntax]]
== 语法

[source, cli, subs="+macros"]
----
revive volumeGroup pass:quotes[[_volumeGroupName_]]
----


[[parameter]]
== 参数

|===
| 参数 | Description 


 a| 
`VolumeGroup`
 a| 
要设置为最佳状态的卷组的名称。将卷组名称用方括号([])括起来。

|===


[[minimum-firmware-level]]
== 最低固件级别

6.10
