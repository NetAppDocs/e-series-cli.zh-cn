= 测试外部密钥管理通信 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
`sStart storageArray externalKeyManagement test`命令可使用已配置的凭据(证书、KMIP服务器的地址和KMIP端口号)来验证存储阵列是否能够与外部KMIP服务器进行通信。



[[supported-arrays]]
== 支持的阵列

此命令适用于单个 E4000、E2800、E5700、EF600、EF300、EF50 和 EF80 存储阵列。不适用于 E2700 或 E5600 存储阵列。



[[roles]]
== 角色

要在 E4000、E2800、E5700、EF600、EF300、EF50 或 EF80 存储阵列上执行此命令，必须具有 Security Admin 角色。



[[context]]
== 环境

[NOTE]
====
此命令仅适用于外部密钥管理。

====


[[syntax]]
== 语法

[source, cli]
----
start storageArray externalKeyManagement test
----


[[parameters]]
== Parameters

无
