= 设置存储阵列主机 I/O 协议 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
该 `set storageArray hostIoProtocol`命令在存储阵列级别配置主机 I/O 协议。



== 支持的阵列

此命令适用于任何单个存储阵列，包括 E4000、E2700、E5600、E2800、E5700、EF600、EF300、EF50 和 EF80 阵列，前提是所有 SMcli 包均已安装。



== 角色

要在 E4000、E2800、E5700、EF600、EF300、EF50 或 EF80 存储阵列上执行此命令，必须具有 Support Admin 角色。



== 语法

[source, cli, subs="+macros"]
----
set storageArray hostIoProtocol={"FC" | "ISCSI" | "ISER" | "nvmeIb" | "nvmeFc" | "nvmeRoce" | "SAS" | "SRP"}
----


== 参数

[cols="2*"]
|===
| 参数 | Description 


 a| 
`set storageArray hostIoProtocol`
 a| 
允许您指定要用于存储阵列的主机 I/O 协议。有效选项为：FC、ISCSI、ISER、nvmeIb、nvmeFc、nvmeRoce、SAS 或 SRP。

|===


== 最低固件级别

12.0
