= 删除电子邮件警报收件人 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
`delete emailAlert`命令可从电子邮件警报配置中删除收件人电子邮件地址。



[[supported-arrays]]
== 支持的阵列

此命令适用于单个 E4000、E2800、E5700、EF600、EF300、EF50 和 EF80 存储阵列。不适用于 E2700 或 E5600 存储阵列。



[[roles]]
== 角色

要在 E4000、E2800、E5700、EF600、EF300、EF50 或 EF80 存储阵列上执行此命令，必须具有 Storage Admin 或 Support Admin 角色。



[[syntax]]
== 语法

[source, cli, subs="+macros"]
----
delete emailAlert
       (allEmailRecipients |
        emailRecipients pass:quotes[[_emailAddress1 ... emailAddressN_]])
----


[[parameters]]
== Parameters

|===
| 参数 | Description 


 a| 
`所有电子邮件接收器`
 a| 
用于删除所有电子邮件收件人。



 a| 
`emailRecipients`
 a| 
用于删除收件人地址。请将电子邮件地址用方括号([])括起来。

|===


[[examples]]
== 示例

[listing]
----

SMcli -n Array1 -c "delete emailAlert allEmailRecipients;"

SMcli -n Array1 -c "delete emailAlert emailRecipients ["person1@email.domain.com" "person3@email.domain.com"];"

SMcli completed successfully.
----
