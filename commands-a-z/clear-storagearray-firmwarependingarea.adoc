= 清除存储阵列固件待处理区域 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
`clear storageArray firmwarePendingArea`命令可删除先前从待定区域缓冲区下载的固件映像或NVSRAM值。



== 支持的阵列

此命令适用于任何单个存储阵列，包括 E4000、E2700、E5600、E2800、E5700、EF600、EF300、EF50 和 EF80 阵列，前提是所有 SMcli 包均已安装。



== 角色

要在 E4000、E2800、E5700、EF600、EF300、EF50 或 EF80 存储阵列上执行此命令，必须具有 Storage Admin 角色。



== 环境

[NOTE]
====
*可能会损坏存储阵列配置*-运行此命令后、存储阵列中现有待定区域的内容将被删除。

====


== 语法

[source, cli]
----
clear storageArray firmwarePendingArea
----


== Parameters

无
