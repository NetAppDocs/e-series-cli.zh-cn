= 停止托盘定位 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
`stop tray locate`命令可关闭由`sStart tray locate`命令打开的托盘上的指示灯。



== 支持的阵列

此命令适用于任何单个存储阵列，包括 E4000、E2700、E5600、E2800、E5700、EF600、EF300、EF50 和 EF80 阵列，前提是所有 SMcli 包均已安装。



== 角色

要在 E4000、E2800、E5700、EF600、EF300、EF50 或 EF80 存储阵列上执行此命令，必须具有 Storage Admin 角色。



== 语法

[source, cli]
----
stop tray locate
----


== Parameters

无



== 最低固件级别

6.10
