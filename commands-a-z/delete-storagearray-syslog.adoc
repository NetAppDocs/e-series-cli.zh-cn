= 删除存储阵列 syslog 配置 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
使用`delete storageArray syslog`命令可以删除用于存储审核日志的指定系统日志配置。



== 支持的阵列

此命令适用于单个 E4000、E2800、E5700、EF600、EF300、EF50 和 EF80 存储阵列。不适用于 E2700 或 E5600 存储阵列。



== 角色

要在 E4000、E2800、E5700、EF600、EF300、EF50 或 EF80 存储阵列上执行此命令，必须具有 Security Admin 角色。



== 语法

[source, cli]
----
delete storageArray syslog (allServers | id="<id>")
----


== Parameters

[cols="2*"]
|===
| 参数 | Description 


 a| 
`所有服务器`
 a| 
删除所有系统日志配置。



 a| 
`id`
 a| 
要删除的系统日志服务器的ID。可以使用`show storageArray syslog`命令获取此ID。

|===
