= 删除一致性组 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
使用`delete ConsistencyGroup`命令可删除快照一致性组。



[[supported-arrays]]
== 支持的阵列

此命令适用于任何单个存储阵列，包括 E4000、E2700、E5600、E2800、E5700、EF600、EF300、EF50 和 EF80 阵列，前提是所有 SMcli 包均已安装。



[[roles]]
== 角色

要在 E4000、E2800、E5700、EF600、EF300、EF50 或 EF80 存储阵列上执行此命令，必须具有 Storage Admin 角色。



[[context]]
== 环境

此命令的工作方式有两种：

* 您可以同时删除一致性组和一致性组包含的存储库卷。
* 您只能删除一致性组、并保持一致性组中的存储库卷完好无损。




[[syntax]]
== 语法

[source, cli, subs="+macros"]
----
delete consistencyGroup pass:quotes[[_"consistencyGroupName"_]]
[deleteRepositoryMembers=(TRUE | FALSE)]
----


[[parameter]]
== 参数

|===
| 参数 | Description 


 a| 
`ConsistencyGroup`
 a| 
要删除的快照一致性组的名称。将快照一致性组名称用双引号("")括在方括号([])内。



 a| 
`dDeleteRepositoryMembers`
 a| 
用于在存储库卷上删除或保留存储库卷的设置。要删除存储库卷、请将此参数设置为`true`。要保留存储库卷、请将此参数设置为`false`。默认设置为`false`。

|===


[[minimum-firmware-level]]
== 最低固件级别
