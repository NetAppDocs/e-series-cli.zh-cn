= 显示存储阵列不可读扇区 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
`sstorageArray unreadableSectors`命令可返回一个表、其中列出了存储阵列中无法读取的所有扇区的地址。



[[supported-arrays]]
== 支持的阵列

此命令适用于任何单个存储阵列，包括 E4000、E2700、E5600、E2800、E5700、EF600、EF300、EF50 和 EF80 阵列，前提是所有 SMcli 包均已安装。



[[roles]]
== 角色

要在 E4000、E2800、E5700、EF600、EF300、EF50 或 EF80 存储阵列上执行此命令，必须具有 Storage Admin 或 Storage Monitor 角色。



[[context]]
== 环境

返回的表将按列标题组织、以显示以下信息：

* 卷用户标签
* 逻辑单元号(LUN)
* 可访问(主机或主机组)
* 日期/时间
* 卷相对逻辑块地址(十六进制格式—0xnnnnnnnn)
* 驱动器位置(托盘t、插槽)
* 驱动器相对逻辑块地址(十六进制格式—0xnnnnnnnn)
* 故障类型


数据首先按卷用户标签进行排序、然后按逻辑块地址(LBA)进行排序。表中的每个条目对应一个扇区。



[[syntax]]
== 语法

[source, cli]
----
show storageArray unreadableSectors
----


[[parameters]]
== Parameters

无
