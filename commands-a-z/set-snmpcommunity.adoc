= 更新 SNMP 社区 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
使用`set snmpCommunity`命令可为现有简单网络管理协议(Simple Network Management Protocol、SNMP)社区创建新名称。



[[supported-arrays]]
== 支持的阵列

此命令适用于单个 E4000、E2800、E5700、EF600、EF300、EF50 和 EF80 存储阵列。不适用于 E2700 或 E5600 存储阵列。



[[roles]]
== 角色

要在 E4000、E2800、E5700、EF600、EF300、EF50 或 EF80 存储阵列上执行此命令，必须具有 Storage Admin 或 Support Admin 角色。



[[syntax]]
== 语法

[source, cli, subs="+macros"]
----
set snmpCommunity communityName=pass:quotes["_snmpCommunityName_"]
newCommunityName=pass:quotes["_newSnmpCommunityName_"]
----


[[parameters]]
== Parameters

[cols="2*"]
|===
| 参数 | Description 


 a| 
`社区名称`
 a| 
要重命名的现有SNMP社区的名称。将SNMP社区名称用双引号("")括起来。



 a| 
`newCommunityName`
 a| 
要为SNMP社区指定的新名称。将SNMP社区名称用双引号("")括起来。

|===
