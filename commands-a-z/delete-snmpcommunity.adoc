= 取消注册 SNMP 社区 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
使用`delete snmpCommunity`命令可删除先前使用`create snmpCommunity`命令创建并注册的现有简单网络管理协议(Simple Network Management Protocol、SNMP)社区。删除SNMP社区会有效地取消注册该社区。此外、还会删除与该社区关联的任何陷阱目标。



[[supported-arrays]]
== 支持的阵列

此命令适用于单个 E4000、E2800、E5700、EF600、EF300、EF50 和 EF80 存储阵列。不适用于 E2700 或 E5600 存储阵列。



[[roles]]
== 角色

要在 E4000、E2800、E5700、EF600、EF300、EF50 或 EF80 存储阵列上执行此命令，必须具有 Storage Admin 角色。



[[syntax]]
== 语法

[source, cli, subs="+macros"]
----
pass:quotes[delete snmpCommunity communityName="_snmpCommunityName_"]
----


[[parameters]]
== Parameters

[cols="2*"]
|===
| 参数 | Description 


 a| 
`社区名称`
 a| 
要删除的SNMP社区的名称。将SNMP社区名称用双引号("")括起来。

|===
