= 测试电子邮件警报配置 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
使用`sStart emailAlert test`命令、您可以通过发送电子邮件示例来测试警报配置。



== 支持的阵列

此命令适用于单个 E4000、E2800、E5700、EF600、EF300、EF50 和 EF80 存储阵列。不适用于 E2700 或 E5600 存储阵列。



== 角色

要在 E4000、E2800、E5700、EF600、EF300、EF50 或 EF80 存储阵列上执行此命令，必须具有 Storage Admin 或 Support Admin 角色。



== 语法

[source, cli]
----

start emailAlert test
----


== Parameters

无



== 示例

[listing]
----

SMcli -n Array1 -c "start emailAlert test;"

The sample alert message was successfully sent to the email addresses.

SMcli completed successfully.
----


== 最低固件级别

8.40
