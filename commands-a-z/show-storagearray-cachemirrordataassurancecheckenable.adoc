= 显示存储阵列缓存镜像数据保证检查启用 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
`sstorageArray cacheMirrorDataAssuranceCheckEnable`命令可返回缓存镜像数据保证检查功能的启用状态。



[[supported-arrays]]
== 支持的阵列

此命令适用于任何单个存储阵列，包括 E4000、E2700、E5600、E2800、E5700、EF600、EF300、EF50 和 EF80 阵列，前提是所有 SMcli 包均已安装。



[[roles]]
== 角色

要在 E4000、E2800、E5700、EF600、EF300、EF50 或 EF80 存储阵列上执行此命令，必须具有 Storage Admin 或 Storage Monitor 角色。



[[syntax]]
== 语法

[source, cli]
----
show storageArray cacheMirrorDataAssuranceCheckEnable
----


[[parameters]]
== Parameters

无



[[minimum-firmware-level]]
== 最低固件级别

8.41新命令参数。
