= 测试系统日志配置 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
`sStart syslog test`命令可发送一条示例消息以测试系统日志配置。



[[supported-arrays]]
== 支持的阵列

此命令适用于单个 E4000、E2800、E5700、EF600、EF300、EF50 和 EF80 存储阵列。不适用于 E2700 或 E5600 存储阵列。



[[roles]]
== 角色

要在 E4000、E2800、E5700、EF600、EF300、EF50 或 EF80 存储阵列上执行此命令，必须具有 Storage Admin 或 Support Admin 角色。



[[syntax]]
== 语法

[source, cli]
----
start syslog test
----


[[parameters]]
== Parameters

无



[[examples]]
== 示例

[listing]
----

SMcli -n Array1 -c "start syslog test;"

The sample alert message was successfully sent to the syslog servers.

SMcli completed successfully.
----


[[minimum-firmware-level]]
== 最低固件级别

8.40
